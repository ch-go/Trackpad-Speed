# WindowOffset · 窗口微错位

**针对系统 App Exposé 自动重排窗口预览、导致每次都要重新找窗口的痛点。**

使用同一应用的多个窗口时，App Exposé 的预览位置可能发生变化。原本已经记住的窗口位置被打乱后，切换窗口就变成了反复辨认和寻找。

WindowOffset 是一个轻量的 macOS 菜单栏工具：自动把同一应用中左上角重合的窗口向右下微微错开，尝试缓解这类窗口在原生 App Exposé 中的自动重排，让依靠预览位置寻找窗口更顺手。

**保留系统原生 App Exposé，只微调窗口位置，不替换系统预览或窗口切换界面。** 微错位对排列的影响并不是 macOS 保证的规则，因此工具无法锁定预览顺序或保证完全消除重排。

## 主要功能

- **自动错开重合窗口**：向右、向下各偏移 1 个逻辑点，逐点寻找空位；窗口大小可以不同。
- **保留窗口大小**：只调整位置，不缩小、不放大。接近铺满屏幕的窗口偏移后，允许右侧或底部少量越界。
- **按新增顺序处理**：新窗口与已有窗口重合时，优先保留已跟踪窗口的位置，让新窗口寻找下一个空位。
- **已有错位保持原样**：不统一排列所有窗口，不改变窗口前后叠放顺序。
- **支持双击铺满后重新调整**：双击标题栏、拖动或调整大小后会重新检查，不因位置曾经处理过而跳过主动操作。
- **立即响应操作**：没有人为设置的固定等待；鼠标释放后立即检查，避免与拖动争抢。系统通信和调度仍会有耗时。
- **支持多显示器与不同缩放**：使用逻辑点计算偏移，兼容不同屏幕布局。
- **缓解 App Exposé 自动重排的痛点**：通过微错位尝试减少重合窗口预览排列变化带来的寻找成本，同时保留系统原生 App Exposé。

例如，已有窗口位于 `(0,33)`、`(1,34)`、`(2,35)`，新窗口出现在 `(0,33)` 时，会移动到 `(3,36)`。新窗口本来就没有重合时不会移动；关闭窗口留下的空位也可以再次使用。

## 菜单栏功能

| 选项 | 作用 |
| --- | --- |
| 自动处理 | 开启或暂停自动错位 |
| 立即处理当前应用 | 手动检查前台应用，自动处理暂停时也可使用 |
| 登录时自动启动 | 开启后在下次登录时运行，默认关闭 |
| 辅助功能授权 | 查看状态、打开授权引导 |
| 打开日志文件夹 | 查看处理原因、操作请求与实际结果 |
| 退出 | 停止后续处理，不撤销已经完成的偏移 |

## 开始使用

1. 将 `WindowOffset.app` 放到固定位置，建议放入“应用程序”文件夹，然后打开。
2. 在 **系统设置 → 隐私与安全性 → 辅助功能** 中添加并开启 WindowOffset。
3. 保持“自动处理”开启，正常使用应用窗口和系统 App Exposé 即可。

需要 macOS 13 或更高版本。更新后请退出旧版再打开新版；如果系统提示重新授权，请重新添加当前位置的应用。

## 哪些窗口会处理？

只处理**同一应用中左上角重合的普通窗口**。新建、移动、缩放、双击标题栏以及切换窗口时都会检查；另有每 2 秒一次的补漏检查。

保留菜单栏的铺满窗口也会处理。最小化窗口、浮动面板、原生独立 Space 全屏窗口和不可移动的窗口会跳过。

创建顺序以工具收到的创建通知或首次发现的顺序为准。首次启动时，无法还原已有窗口过去的真实创建顺序。

## 日志与隐私

日志仅保存在本机，不上传，不记录窗口标题、终端输出、网页或文档内容，也不监听键盘。

通过菜单“打开日志文件夹”访问：

```text
~/Library/Logs/WindowOffset/
```

日志记录应用、窗口位置和大小、调整原因、实际结果及越界量。单个文件约 2 MiB，另保留 3 份历史记录，合计约 8 MiB，旧记录自动轮转。

## 使用说明

App Exposé 的最终排列由 macOS 决定，微错位不保证固定的预览顺序。个别应用可能拒绝调整或自行恢复窗口位置，可通过日志查看实际结果。
